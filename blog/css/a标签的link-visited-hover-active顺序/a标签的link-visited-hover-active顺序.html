a标签的link-visited-hover-active样式的设置顺序

这是一个非常基础的面试题，但是到2024年的今天，我也没在实际中用到过 😅， 只在刚毕业那会出来找工作刷到过这道题目，我都快要忘记了，没想到今天面试还是遇上了。

正确顺序

  1. link - 设置a对象在未被访问前的样式表属性
  2. visited - 设置已经访问过的样式
  3. hover - 设置鼠标悬浮的样式
  4. active - 设置在被激活（鼠标点击时）的样式

理解

因为浏览器对于css之间，是会覆盖，简而言之，相同元素间（同css选择比重），定义在后的会覆盖定义在前的，所以才会衍生出这个问题。

默认状态是link，这个放在css的最上面，便于其他伪类覆盖；
点击过后会添加伪类 visited， 这个状态下的样式应该放在 link 之后；
鼠标悬浮在a标签上，会添加伪类 hover， 这个状态的优先级应该比上面这两个都要高，所以要排在 link 以及 visited 之后；
最后是 active ，这个状态是在鼠标点击到释放这个阶段中添加的，所以应该比 hover 的优先级要更高一点，应该放在最后面；
