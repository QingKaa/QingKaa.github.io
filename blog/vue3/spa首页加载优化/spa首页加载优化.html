spa首页加载优化

spa首页加载慢，可以从以下几个方面进行优化：

代码分割

可以通过webpack或者vite等打包工具，对代码进行分包，首页部分单独抽离出来，加载首页部分，其他部分按需加载。

Webpack 5

Webpack 5 通过使用 optimization.splitChunks 来配置代码分割：

// webpack.config.js

const path = require('path');

module.exports = {
  // 入口文件
  entry: './src/index.js',
  // 输出文件
  output: {
    filename: '[name].[contenthash].js',
    path: path.resolve(__dirname, 'dist'),
    clean: true,
  },
  // 优化配置, 分包
  optimization: {
    splitChunks: {
      chunks: 'all',
    },
  },
};

optimization.splitChunks.chunks: 'all'： 表示Webpack会自动将所有的代码模块分割成独立的块。

Vite 配置代码分割

Vite会根据实际使用情况自动进行代码分割。

懒加载

对于页面上的图片、组件等，可以通过懒加载的方式，延迟加载的方式，减少首页的加载时间

动态导入（dynamic import）

const MyComponent = () => import('./MyComponent.vue');

Vue Router 配置懒加载

const routes = [
  {
    path: '/about',
    component: () => import('./views/About.vue')
  }
];

vue3.2 Suspense 组件

Vue 3.2引入了Suspense组件，可以更优雅地处理异步组件的加载状态。可以将异步组件包裹在Suspense组件内，并指定fallback内容（加载过程中显示的内容）

优化静态资源

可以对图片，字体包等进行压缩，减小文件大小。

减少HTTP请求

首页的请求数量过多，可以通过减少请求数量，减少请求大小，减少请求次数来优化首页加载速度。

使用缓存策略

利用浏览器缓存机制和HTTP缓存头（如Expires、Cache-Control等），以减少重复加载相同资源的次数，加快页面的加载速度。

http 缓存机制

缓存策略：
强制缓存：

如果资源在有效期内，浏览器将直接从缓存中加载资源。

强制缓存策略通过在响应头中设置Expires或Cache-Control字段来控制缓存的有效期。常用的Cache-Control字段值包括max-age和s-maxage。

实现方式：在HTTP响应头存放Cache-Control相对时间或Expires绝对时间来判断资源是否过期，若同时存在，Cache-Control的优先级会高一些，所以一般用前者。

协商缓存：

浏览器在访问资源之前会检查本地是否已经存在该资源的缓存副本，如果存在且未过期，则直接从缓存加载。此时不会向服务器发送任何请求。
只有浏览器判断缓存无过期，直接使用浏览器本地缓存，主动方是浏览器。

实现方式两种： 1 在HTTP响应头带上Last-Modified字段记录最后修改时间，然后在HTTP请求头带If-Modified-Since比较两者时间。两者都是记录页面最后修改时间，一致则返回304表示未改变；

2 在HTTP响应头带上Etag唯一标识响应资源，然后请求头带上IF-None-Match字段（携带的值就是Etag的值），该方式能以防时间被篡改，更为可靠，所以Etag这种方式的优先级也会更高。

常见的http缓存头：

Cache-Control :
用于定义缓存策略和行为。可以包含以下指令

public：响应可以被任何缓存（包括浏览器和代理服务器）缓存。
private：响应只能被用户代理缓存，不能被共享缓存（如CDN）缓存。
no-cache：强制重新验证缓存的内容。
no-store：不缓存任何内容，每次请求都必须从源服务器获取数据。
max-age=<seconds>：指定缓存内容的最大有效时间（以秒为单位），超过这个时间缓存将被视为过期。
must-revalidate：缓存内容过期后，必须重新验证其有效性。
s-maxage=<seconds>：与max-age类似，但仅对共享缓存（如CDN）有效

示例：
Cache-Control: max-age=3600, public

Expires:
过期时间，指定缓存内容的到期时间。相对于Cache-Control，Expires是一个旧的字段，已被Cache-Control更替。

Last-Modified:
指示资源最后一次修改的时间。浏览器可以在后续请求中使用 If-Modified-Since 头来检查资源是否已被修改。

ETag:
提供一个唯一的标识符（通常是哈希值）来表示资源的特定版本。浏览器可以使用If-None-Match头将ETag值发送到服务器，以检查资源是否已更改。

Vary:
指定缓存策略的变量，例如Accept-Encoding可以指定缓存响应是根据请求的内容编码进行缓存的。

组合使用示例:

Cache-Control: public, max-age=86400
Expires: Tue, 21 Oct 2024 07:28:00 GMT
Last-Modified: Mon, 20 Oct 2024 07:28:00 GMT

Cache-Control: public, max-age=86400 表示资源可以被缓存，缓存时间为24小时（86400秒）。 Expires 提供了一个具体的到期时间。 Last-Modified 用于标记资源的最后修改时间，允许浏览器进行条件请求。
