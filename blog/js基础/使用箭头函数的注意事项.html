使用箭头函数的注意事项

清咖
2024-07-03
js基础
tags: ES6JavaScript

this指向

箭头函数内部没有自己的this上下文，在箭头函数内部使用 this 会指向外层的this上下文。

function Person() {
    this.age = 0;

    setInterval(() => {
        // `this` here is the same as `this` in Person
        this.age++; 
    }, 1000);
}

箭头函数不能作为构造函数

箭头函数不能使用 new 声明，因此不能作为构造函数使用。

const Example = () => {}; // Error: Example is not a constructor
const obj = new Example(); // TypeError: Example is not a constructor

没有 arguments 对象

箭头函数自身没有 arguments 对象。
可以使用 剩余参数 的方式获取所有的参数。

function traditionalFunction() {
    console.log(arguments); // Arguments(3) [1, 2, 3]
}

const arrowFunction = (...args) => {
		console.log(args) // [1, 2, 3]
    console.log(arguments); // ReferenceError: arguments is not defined
}

traditionalFunction(1, 2, 3);
arrowFunction(1, 2, 3);

不能用作 Generator 函数

箭头函数不具备 Generator.prototype属性，因此不能用作 Generator 函数。

const generatorFunction = function* () {
    yield 1;
};

const arrowGeneratorFunction = *() => { // SyntaxError
    yield 1;
};

可以省略花括号

如果箭头函数的函数体只有一条语句，并且该语句返回了一个值，那么可以省略花括号和 return 语句。

const add = (a, b) => a + b; // 省略了花括号和return
