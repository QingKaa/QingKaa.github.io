行内元素与块级元素以及行内块元素

清咖
2024-07-10
html
tags: html面试基础题

html元素可分为三种类型：行内元素、块级元素以及行内块元素。
可以通过display属性来控制元素类型。
行内元素： display: inline;
块级元素： display: block;
行内块元素： display: inline-block;

行内元素

可以通过设置 css 的 display: inline; 可以将元素转换成行内元素

特点

  • 一行内可以显示多个行内元素。
  • 直接设置宽、高属性无效。
  • 默认宽度就是其内容的宽度。
  • 行内元素内部只能容纳文本或者行内元素（不能容纳块级元素）。

常见的行内元素

常见的行内元素有： span, a, strong, i, b, img, input, select

块元素

通过设置 css 的 display: block; 可以将元素转换成快元素

特征

  • 自己独占一行
  • 高度、宽度都可以设置
  • 宽度默认是容器（父级宽度）的100%。
  • 是一个容器盒子，内部可以容纳文本或者行内元素或者块级元素。

常见的块级元素

常见的块级元素有： div, p, h1 - h6, ul, li, table

行内块元素

可以通过设置 css 的 display: inline-block; 可以将元素转换成行内块元素

特征

具备了行内元素以及块元素的特征。

  • 和相邻行内元素（行内块）在一行上，但是他们之间会有空白缝隙。一行可以显示多个（行内元素特点）。
  • 默认宽度就是它本身内容的宽度（行内元素特点）。
  • 高度，行高、外边距以及内边距都可以控制（块级元素特点）

常见的行内块元素

有几个特殊的标签： img, input, td，同时具备了行内元素以及块级元素的特点。某种程度上可以称呼他们是行内块元素。

总结

元素模式元素排列设置样式默认宽度包含
行内元素一行可以放多个行内元素不可以设置宽度高度它本身内容的宽度容纳文本或其他行内元素
块级元素一行只能放一个块级元素可以设置宽度高度容器的100%容器级可以包含的任何标签
行内块元素一行可以放多个行内块元素可以设置宽度高度它本身内容的宽度
